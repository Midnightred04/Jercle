Replace these files in your GitHub repository:

- style.css
- script.js

Keep existing firebase-config.js, photos, and all other files.

FIREBASE RULES (REQUIRED):
1. Go to Firebase Console > Firestore Database > Rules.
2. Open firestore.rules supplied here. Replace REPLACE_WITH_JERCLE_USER_UID with the UID of your Jercle Authentication user (the same UID used in your currently published rules). DO NOT publish the placeholder.
3. Paste the complete rules into the Firebase Rules editor and click Publish.
4. Existing brainstorm documents need no migration. The rule allows changing only name and description while preserving createdAt.
